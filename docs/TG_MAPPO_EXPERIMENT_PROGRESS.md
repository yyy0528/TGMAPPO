## 6. 第 4 步：实现并监督预训练一步 WM

目标：先学会预测，再辅助 Actor。这里是数值/图模型的监督学习，无需语言模型 SFT 或人工写指令数据。

- [ ] 输入：截至 t 的可用观测历史、过去动作及当前候选动作；保持与 TG-MAPPO 约定的信息范围一致。
- [ ] 建立图/历史编码，区分不依赖当前转发动作的拓扑分支和依赖候选动作的业务分支。
- [ ] 先跑通最小预测头，如发送成功概率、队列变化；再扩充下一时隙链路、本步投递/丢弃等目标。
- [ ] 标签由第 3 步生成；WAIT 不参与“发送成功/失败”分类损失，不能把 WAIT 标为发送失败。
- [ ] 先用少量样本验证损失和梯度，再做小数据过拟合、验证集评估和简单预测基线对照。
- [ ] 记录连续误差、概率校准、稀有事件指标及采集/预训练成本，保存最优权重、网络配置和归一化参数。

产物：WM 代码、预训练入口、数据版本、真实 checkpoint、独立预测评估报告。
完成标准：数据/损失通过检查，相关预测优于相应简单基线；无效预测头不当作可靠决策依据。
完成后进入第 5 步。

## 7. 第 5 步：冻结 WM，接入 TG-MAPPO Actor

目标：保留原 TG-MAPPO 决策主干，增加候选动作后果信息。

- [ ] 采样前用冻结 WM 对合法候选动作生成特征，用 `eval/no_grad`，Actor 自己产生最终动作。
- [ ] 原图编码与候选预测特征融合；不在采样后用规则替换动作。
- [ ] 保存采样时的 WM 预测、模型/归一化版本、掩码、旧 log probability 和价值；PPO 重算复用相同输入。
- [ ] 检查更新前新旧概率比接近 1、非法动作概率为 0、全 WAIT 有限，WM 权重在 PPO 更新前后不变。
- [ ] 开启和关闭 WM 都做短训练、权重保存及冻结评估；PM 此阶段保持关闭。
- [ ] 用消融检验预测结构价值，另设参数量接近的加宽/加深 Actor 对照；不能把增加参数量本身当作创新收益。

产物：可开关的 TG-MAPPO+WM、集成测试、模型权重和独立评估结果。
完成标准：原环境、原 TG-MAPPO 的 PPO 流程下，候选特征确实进入 Actor，采样/重算一致，WM 冻结，训练及评估通过。
完成后进入第 6 步。

## 8. 第 6 步：加入 PM 进度奖励

目标：保留环境任务奖励，用历史进度的差分辅助时间信用分配。

- [ ] 使用真实成功/失败包轨迹训练独立 PM；输入只能是当前及过去的路径/拓扑/TTL 等前缀信息，最终结果只作监督标签。
- [ ] 成功失败分层采样、按包平衡前缀；未结束轨迹作为删失样本，不能直接标为失败。
- [ ] 验证并冻结 PM，明确包级得分如何聚合为团队势函数；按回合初始包数归一化。
- [ ] 结束包势函数置零；单纯 rollout 截断保留进度和 bootstrap；PM 版本与塑形系数在完整任务中固定。
- [ ] 在原环境返回结果之后、GAE/returns 之前，由奖励模块计算 `r_progress = alpha * (gamma * Phi_tp1 - Phi_t)`，并得到 `r_train = r_env + r_progress`。
- [ ] 分别保存 r_env、r_progress、r_train；Critic 学习 r_train 对应的回报，PPO buffer 仍使用当前策略的真实环境交互。
- [ ] 测试 alpha=0 恢复基线奖励、终止/截断边界和差分公式；分别验证 PM 单独启用及 WM+PM 组合。

产物：PM 预训练及评估、真实 checkpoint、进度奖励开关、分项奖励日志和联调结果。
完成标准：真实 PM 独立训练/验证并冻结，分项奖励可追踪，无未来信息泄漏，GAE 使用正确 r_train。
完成后进入第 7 步。
