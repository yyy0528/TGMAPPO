## 4. 失败、必须修改及资源结论

当前能力验收 **11 项失败**：WM/PM/研究策略三 trainer、三个正式 backend、EARP、CUDA、
resume、学习策略 checkpoint 评估、当前 3.10 解释器启动旧 TG。
见 [逐项原因、位置与建议](UNIMPLEMENTED_AND_FAILED_TESTS.md)，本轮不修复。

另有单回合绘图无 marker、旧指标/预算/移动定义和 requirements 缺项，均已单列，未静默修改。
优先顺序应为研究环境基础 PPO → 独立 WM/PM → 冻结接入 → 完整恢复/评估 → 同预算多种子与 GPU 实测。

硬件为 RTX 4060 Laptop，8188 MiB；两个项目解释器均使用 CPU PyTorch。
因此未验收 6GiB 峰值目标、模型 GPU 速度或 8GB 整体可承受性。
短训练、规则投递率和不同旧环境的结果不能用于证明创新收益或算法排名。
