## 2. 已复现问题：原因、修复与验证

| 问题 | 原因 | 修复 | 验证 |
|---|---|---|---|
| 错误模型输出仍使环境前进一步 | 策略价值、候选特征在 `step_joint` 后写 buffer 时才被校验 | 采样阶段先核验观测、动作/价值/循环状态、候选特征，再执行环境 | NaN 价值和错误候选形状被拒绝，环境仍为第 0 步 |
| WM 可在 bootstrap 时切换版本 | 版本检查位于 bootstrap 计算之前 | bootstrap 特征校验及计算结束后再次核对 WM/PM/策略版本 | 在 bootstrap 中主动变更版本的替身被拒绝 |
| GAE 可传播 NaN | 直接调用 `RolloutBatch.compute_gae` 未检查折扣和 bootstrap 的有限性 | 校验 gamma/lambda、bootstrap、终止边界和转移数据 | 非有限输入被拒绝；多步结果与独立折扣求和一致 |
| 错位 agent 观测可进入 buffer | 原校验只核对动作合法性，没有核对 agent 槽位 | 核对 `agent_id == 槽位`、观测/图形状、快照节点数 | 重复/错误 agent ID 的观测被拒绝 |
| 配置覆盖拼错字段抛内部 TypeError | 直接把字段交给 dataclass `replace` | 先检查 `section.field` 及已知字段，返回 ValueError | `runtime.seeed` 清楚报错 |
| 拼错规则策略名称静默运行地理策略 | 非 random 的 mode 全部进入 geographic 分支 | 构造时显式限制支持名称 | `randmo` 被拒绝，两个合法策略正常运行 |
| 损坏转移可写入磁盘 | 归档前只检查回合 ID | 写入前核验完整回合、连续状态/观测、schema、包结果守恒及 JSON 可序列化性 | schema 错误在创建回合目录前被拒绝 |
| 空目录可被登记为有效回合 | manifest 只检查目录存在 | 要求转移和包轨迹文件均存在且非空 | 空回合目录不能生成有效 manifest |
| 损坏 manifest/checkpoint 抛 AttributeError/TypeError | 未检查 JSON 顶层结构、必需字段和字段类型 | 在文件边界验证，转换为带说明的 ValueError | 缺字段、错误列表/对象类型均清楚报错；真实 CLI 无 traceback、退出码为 2 |
| 非法数据拆分比例可被接受 | 独立 `episode_split` 函数依赖外部配置校验 | 函数自身检查有限、正比例及测试集余量 | 负比例、比例之和超限、NaN 均被拒绝 |
| 不同节点规模数据混用 | manifest 缺少维度，训练入口仅核对环境版本 | 从回合起始记录核对统一节点/动作 schema，写入 manifest；trainer 调用前再次比较配置 | 9/16 节点混合数据被拒绝，9 节点数据不能按 25 节点配置训练 |
| 同一场景泄漏到不同集合 | 原拆分仅按 episode ID 检查重叠 | 记录回合 seed，拒绝同一 seed 跨 train/validation/test | 不同 ID、相同 seed 跨集合时被拒绝 |

首次新增函数测试执行了 30 项，出现 12 个失败断言和 4 个异常条目（包含子测试），
随后修复；新增模块测试又复现了上述数据规模/种子管理的 3 个失败用例。
这些回归用例保留在测试代码中，最终完整运行全部通过。

## 3. 模块与联调场景

环境模块覆盖 4、9、16、25、36 节点；规则随机/地理路由；0、12、31 等种子；
全部节点移动、拓扑变化、40% 随机丢包、100% 丢包和无可达邻居。
独立检查实际坐标生成的可见性/动作掩码、包守恒、队列唯一归属、单包单时隙最多一跳、
等待/失败历史、TTL 与任务截止事件，以及成功包真实跳数和端到端时隙时延。

联调通过独立 Python 进程验证：

1. 主脚本、`python -m`、帮助信息和旧算法列表入口。
2. 25 节点、种子 41/42/43 的三个回合采集、回合拆分及归档指标对账。
3. 随机路由、移动和丢包条件下的可重复评估，评估不追加训练数据。
4. 160 时隙任务、7 步 rollout 的持续采集：只在采样边界截断，最后才真实终止。
5. 36 节点移动丢包网络及 25 节点全丢包网络。
6. 数据采集 → WM/PM trainer 接口 → 元信息 checkpoint → 组合模型采样/塑形 → 策略 trainer 接口。
7. 未注册训练器、损坏数据、损坏 checkpoint 和参数拼写错误均清楚失败。
8. 同名输出目录拒绝覆盖，既有报告内容保留。

第 6 项使用 `tests/research_plugin_fixture.py` 中明确标注的测试替身。
它执行接口装配、数据读取、元信息保存/加载和采样；**没有网络梯度训练或学习权重**。
