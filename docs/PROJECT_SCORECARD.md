## 1. 计算规则

本评分表是此次交接使用的工程评估规则，不是外部标准或算法性能排名。
按下面的可验证条目计分：已实现且有对应代码/运行证据得该项满分，未实现或尚无验证证据得 0；
不按主观“完成百分比”给半分。设计协议可得架构分，不能再计作模型训练完成。

`总分 = Σ（条目权重 × 已满足标志）`，已满足标志仅为 0 或 1，权重合计 100。
核心 WM、PM、冻结组合及完整保存恢复仍缺失，不能用文档或测试分抵消，验收直接不通过。

## 3. 分数的含义

当前成果包含可运行研究 Graph-MAPPO 基线、旧路径和数据框架；两个研究创新尚未完整实现。
131/131 是已实现测试范围的通过率；它不是全方案完成率，也不是分支覆盖率或算法准确率。

后续主要缺分为 WM（8 分）、PM（8 分）、冻结组合（7 分）及完整保存恢复（5 分）。
本次三种子是同一短训策略的独立评估，并非三个独立训练种子，因此 D4 不加分；CPU 参数/耗时也不替代 GPU 显存验收。
