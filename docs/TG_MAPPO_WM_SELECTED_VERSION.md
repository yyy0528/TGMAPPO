## 本轮改过什么，为什么不选

动作条件版用Actor动作输出层的行权重形成候选上下文；对合法候选的标准化预测增量取相对差异；用“有增量输出−零增量输出”作残差。参数量和奖励不变，但融合计算与梯度路径改变，最终表现不均衡：种子22达到100%，种子11明显下降，均值低于上一版。因此回选较高均值的旧版，不把新接口的功能正确等同于性能更优。

## 固定入口

当前选择保存在 `configs/tg_wm_active.json`。固定入口 `run_tg_wm_active.py` 验证归档源码、WM、校准、三个策略检查点和报告哈希，直接调用旧源码快照，避免工作区实验代码影响结果。它仍运行原TG-MAPPO和原环境，没有创建新的研究环境。

检查选择（不训练、不评估）：

```powershell
& "D:\anaconda3\envs\buoy_gpu\python.exe" -s run_tg_wm_active.py --check
```

评估旧模型，seed选择训练种子，scene选择评估场景：

```powershell
& "D:\anaconda3\envs\buoy_gpu\python.exe" -s run_tg_wm_active.py --seed 11 --scene 8001
```

该入口只做冻结评估，不重新训练；通用run_algorithm.py入口保持兼容，直接使用通用入口时不能省略WM输入模式、校准及相应模型配置。后续改动以选定配置为基准另开实验目录。
