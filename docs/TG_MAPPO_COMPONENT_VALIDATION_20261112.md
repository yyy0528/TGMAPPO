## 问题与固定设计

1. 冻结WM是否比简单基线更准确：ACK概率与历史链路估计、队列联合变化与零变化、位移与已知运动规则比较，并给校准分箱。
2. 冻结PM是否从包历史学到信息：删失生存NLL、窗口投递Brier与训练集常数风险先验比较。额外比较有限task_v2任务回报MSE，不能称为当前策略的真实V值。
3. 高丢包及快速移动时PM_WM低于PM的现象对应哪些包、节点和动作：记录WAIT、环路、PM近优集差异、WM残差改变动作及线上预测误差。
4. 同一PM_WM检查点仅在推理时关WM残差，检查即时决策依赖；这是干预诊断，不能代替重训后的WM消融。

模型使用既有300回合终点、原PM辅助系数0.1、已选shared/residual_scaled WM；不采用0.2候选，不挑种子或中间最优检查点。独立复制WM/PM并记录SHA，依赖与策略文件及源码快照均锁定。

### 能确定的现象与仍不能确定的原因

1. 高丢包9402种子11：PM有164次活跃WAIT，组合404次，其中295次落在近似PM教师近优集外；节点4/10各等待160次，两回合均长期不转发。关闭残差后组合WAIT增至640次，投递75.00%降至68.75%，说明仅把WM输出关闭不是统一修复。
2. 同条件种子33：组合仅1次WAIT、PM有5次，全部环路计数0，但组合投递64.58%低于PM87.50%。组合两回合ACK失败1360次，PM为1192次；未投递包大量集中在13/17附近。不能把这一类下降解释成WAIT或环路问题。
3. 种子33关闭WM残差后79.17%，改善14.58个百分点，仍低于PM87.50%；种子11却下降。存在种子相关的融合影响，不能按种子选开关或声称已经稳定修好。
4. 9402高丢包三个组合模型的在线队列MSE均比零变化更差，ACK分箱ECE约0.116–0.137，离线202约0.0095。说明离线小幅优势没有在这些访问分布中全部保持；这是观测到的分布/校准问题，尚不足证明某一损失或训练不足是唯一原因。
5. 9402高丢包事实轨迹的WM融合确实改变过转发选择，但没有出现“基础分支转发、融合后最大概率动作改成WAIT”的翻转。只能描述访问状态上的即时分支差异；不能据此排除WM影响历史训练后的基础Actor，也不能从冻结回放唯一归因PPO梯度。
6. PM教师近优集为保持未来位置/其他节点状态的一步近似，不是真实最优标签；离线PM预测优于先验，也不等于其反事实动作排序对所有策略和压力条件正确。本轮没有重跑训练中GAE/优势梯度，不宣称新增训练bug已被修复。
