# MRL-RB简介 #


## 运行 ##
- 直接运行main文件就可以看到5*5网络的训练过程


## agent.py ##
- 该文件夹定义了智能体的一些属性和方法，包括神经网络，动作选择函数，训练函数等等。

## buoy.py ##

- 该文件夹定义了浮标、浮标网络、数据包三个类。

## environment.py ##

- 环境的定义，获取观测，执行动作，生成数据包，网络刷新等函数都在里面。

## replay_buffer.py ##

- 定义了两个经验回放池。

## runner.py ##

- 强化学习的执行文件，主要是智能体与环境交互的过程，也包括奖励值回溯机制。
